# Безопасность и приватность

## Что не должно попадать в GitHub

- `config.local.env` — пользователь, пути, порт
- IP-адреса, MAC, имена Wi‑Fi, пароли
- SSH-ключи, токены GitHub, API-ключи
- Файлы из `~/.ssh`, облачных конфигов, бэкапов

Репозиторий содержит только **общий код**. Личное настраивается локально при `install.sh`.

## Доступ к панели

- Панель слушает `0.0.0.0` — доступна всем в вашей LAN.
- **Пароля нет** — не выставляйте порт в интернет без reverse proxy и авторизации.
- Для доступа извне дома используйте VPN (WireGuard), не проброс порта на роутере.

## Перед публикацией репозитория

```bash
git status
git grep -E '192\.168\.|10\.|172\.(1[6-9]|2[0-9]|3[01])\.|@[a-z].*\.(com|ru)|ssh-ed25519|BEGIN OPENSSH'
```

Если что-то нашлось — уберите из коммита.
